# 📚 考研英语背单词（纯前端版）

一个零依赖、零构建的考研英语背单词网站，直接用浏览器打开即可使用。内置 **6705 个考研词汇**（红宝书词库），支持**间隔重复记忆**、**单词发音**、**测试模式**、**词库总览**和**个性化学习设置**。

## ✨ 功能

- **单词卡片学习**：正面看单词，点击翻转查看音标、词性和释义
- **单词发音**：点击卡片上的 🔊 按钮即可朗读（浏览器自带语音合成）
- **释义分行显示**：不同词性各占一行（词性高亮），卡片和测试界面都更清晰
- **间隔重复记忆**：基于 SM-2 算法（艾宾浩斯遗忘曲线），自动按系统时间安排下次复习
- **自评文案自适应**：新学单词显示「认识 / 不确定 / 不认识」，复习单词显示「记得 / 模糊 / 忘记」
- **忘记/模糊当天复习**：自评「忘记/不认识」或「模糊/不确定」的单词，当天会再次出现（最多 2 次，**刷新后仍有效**）
- **键盘快捷键**：空格/回车翻卡，`1`/`2`/`3` 评分，测试页回车下一题
- **个性化设置**（点击「应用」按钮生效）：
  - 每日新学单词数可调（默认 10 个）
  - 学习顺序可选：按字母序 / 按字母倒序 / 乱序随机
- **学习统计**：今日待学、今日已学、累计已学、连续打卡天数
- **测试模式**（只从已学过的单词中选题）：
  - 看词选义（四选一）
  - 看义拼写（根据释义拼出单词，答案规范化忽略空格/连字符）
  - 进度指示（第 X / Y 题）+ 错题回顾
- **词库总览**：实时搜索（防抖）、只看已学、按字母序/倒序排序、点击展开完整释义与例句、标记学习状态
- **数据导入/导出**：一键备份/恢复学习进度（JSON 文件）
- **重置学习记录**：一键清空学习进度、统计和设置（带二次确认，防止误触）
- **深色模式**：一键切换 🌙/☀️

## 🚀 使用方法

### 方式一：直接用浏览器打开（最简单）
双击 `index.html`，浏览器会自动打开。

> 注：极个别旧浏览器在 `file://` 协议下可能限制本地存储，若学习记录没保存，请用下面的方式二。

### 方式二：本地 HTTP 服务器（推荐，更稳定）
在项目目录下运行以下任意一条命令：

```bash
# 用 Python（系统装了 Python 的话）
python -m http.server 8000

# 或用 VS Code 的 Live Server 插件
```

然后浏览器访问 `http://localhost:8000`。

## 📖 词库说明

- 共 **6705 个单词**，覆盖考研英语核心词汇
- 数据来源：[qwerty-learner](https://github.com/RealKai42/qwerty-learner) 项目的 `2025KaoYanHongBaoShu.json`（考研红宝书词库）
- 每个词条包含：单词、音标、词性、结构化释义（按词性分行）、部分词条含例句和翻译

## 🧠 记忆算法说明

采用 SM-2 间隔重复算法（Anki 同款简化版），**读取系统时间**来安排复习计划：

- 每次复习后根据你的自评（忘记 1 分 / 模糊 3 分 / 认识 5 分）更新单词状态
- 答对次数越多，下次复习间隔越长（1 天 → 6 天 → 成倍增长）
- 答错则回到「明天复习」，直到真正记住
- 间隔达到 30 天以上标记为「已掌握」
- **忘记/模糊的单词当天会再次安排复习**，强化记忆
- 跨天自动重置「今日」统计，新学单词按目标数量补齐
